# SwitchBot Current Settings (example)

自分の設定を記録する表の例。このファイルをコピーして `current-settings.md` を作り、自分のシーンとオートメーションを書く。設定を変えたら表も更新する。下の値は例。

## オートメーション

| オートメーション | 時刻 | 前提条件 | シーン |
| --- | --- | --- | --- |
| 起床 | 毎日 7:00 | なし | 起床 |
| 日中（晴れ） | 毎日 9:00／13:00 | Sunny（自分の都市） | 日中（晴れ） |
| 日中（曇り・雨） | 毎日 9:00／13:00 | Cloudy または Raining（自分の都市） | 日中（曇り・雨） |
| 夕方 | 毎日 17:00 | なし | 夕方 |
| 就寝準備 | 毎日 22:00 | なし | 就寝準備 |

## シーン

| シーン | シーリングライト | カラー電球 |
| --- | --- | --- |
| 日中（晴れ） | 全灯（Full light） | 白、100% |
| 日中（曇り・雨） | Customize 80%、4000K | 白、80%、4000K |
| 夕方 | Customize 70%、3000K | 白、70%、3000K |
| 就寝準備 | 常夜灯（Nightlight） | 白、1% |

- 色温度の流れの例：日中 約 4000K → 夕方 3000K → 夜 2700K（照明の下限）
