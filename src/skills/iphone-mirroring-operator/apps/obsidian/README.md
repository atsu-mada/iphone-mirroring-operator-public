# Obsidian (Text Bridge)

ミラーリング越しでは文字を入力できないため、iPhone の Obsidian を「コピー元」にして、名前などの文字を iPhone のクリップボードへ入れる。

## 手順

1. Vault の中に作業用のフォルダを1つ決める（例：`_mirroring-bridge/`）。iPhone と同期される Vault（iCloud など）であること
2. 入れたい文字列ごとに1つずつノートを作る。本文は**その文字列1行だけ**にし、見出しやプロパティは付けない（全選択でそのままコピーできるようにするため）。ファイル名は `YYYY-MM-DD_<用途><番号>_<内容>.md`
3. iPhone 側へ同期されるのを待つ（iCloud の同期で数十秒）
4. ミラーリングで Obsidian を開き、左上のサイドバーボタン → フォルダを開く → ノートをタップ
5. 本文の行をクリックして編集状態にし、`cmd+a` → `cmd+c`
6. `cmd+1` でホームへ戻り、貼り付け先のアプリを開いて、入力欄をクリック → `cmd+a` → `Delete` → `cmd+v`
7. 作業が終わったら、作ったノートを `~/.Trash/` へ移す（ユーザーが削除してよいと言った場合）。消さずに残すならユーザーに確認する

## 注意

- 編集状態で文字キーを押すとノートが書き換わる。押すのはショートカットだけにする
- サイドバーのファイル一覧で他のノートを開いても、触らずに閉じる
