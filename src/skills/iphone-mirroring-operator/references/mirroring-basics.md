# iPhone Mirroring Basics

どのアプリにも共通する、ミラーリングの接続と基本操作。2026-10-26 に macOS 26.3 と iPhone の組み合わせで確かめた。スライダーやピッカーで値を合わせる方法は [value-tuning.md](value-tuning.md) にまとめてある。

## 接続とロック

| 状態 | 画面の表示 | 対応 |
| --- | --- | --- |
| 初回設定 | 「iPhone on Your Mac」 | 「Continue」→ iPhone のロック解除をユーザーに頼む →「Allow Notifications」は「Don't Allow」→「Require Mac Login」は「Ask Every Time」→「Get Started」 |
| ミラーリングのロック | 「iPhone Mirroring Is Locked」 | Touch ID か Mac のパスワードでの解除をユーザーに頼む。しばらく操作しないと再びロックされる |
| iPhone を使用中 | 「iPhone in Use」 | iPhone 本体をロックして置いてもらう。ユーザーが iPhone の Claude アプリなどでこの会話を見ていると、そのたびに切れる |

## 操作モード

- ユーザーの今のデスクトップがフルスクリーンのアプリだと、ウインドウを手前に持ってこられず、`app_*`（バックグラウンド操作）のクリックが拒否される。`request_full_control` で画面全体の操作を許可してもらい、`open_application` のあと `computer_batch` で操作する
- 作業が終わったら `release_full_control` で戻す
- `app_menu` の「Paste」はクリップボードに触れるため拒否される。貼り付けは `cmd+v` を使う

## 画面の読み方

- 最初に `computer_batch` の `screenshot`（scale 0.5）でウインドウの位置をつかむ。位置は毎回変わりうる
- 以降は `zoom` でミラーリングのウインドウだけを拡大して読む
- クリック座標は全画面の座標で指定する。zoom 画像の座標は「領域の左上 + zoom 上の座標 × 領域の幅 / 画像の幅」で戻す
- 画面の切り替えには1〜3秒かかる。切り替えのあとは `wait` を入れ、次の操作の前に `zoom` で今の画面を確かめる
- 開いた直後の画面は中身の読み込みが遅れることがある（一覧が空に見えるなど）。「消えた」と判断する前に、待つか開き直して確かめる

## 操作をまとめて送るとき

- `computer_batch` に複数の画面遷移を詰めると、1つずれただけで後の操作が別の画面に当たる。遷移ごとに `zoom` を挟むか、遷移が2〜3回ごとに結果を確かめる
- ミラーリングの上に別のアプリの表示（入力補助ツールの小窓など）が重なると、クリックが拒否されて batch が止まる。全体のスクリーンショットを撮り直してから続ける
- 意図しない画面（アイコン設定など）が開いたら、何も変えずに「Cancel」か左上の「<」で閉じ、元の画面に戻ったことを確かめる

## キー操作

| 操作 | 結果 |
| --- | --- |
| `cmd+1` | ホーム画面 |
| `cmd+2` | App スイッチャー |
| `cmd+3` | Spotlight（ただし検索語を入力できないので使えない） |
| `cmd+=` | ウインドウを大きくする（効かないこともある） |
| `cmd+a`、`cmd+c`、`cmd+v`、`Delete` | iPhone 側で効く |
| `type` での文字入力 | 届かない。日本語も英字も「a」に化ける |
| `cmd+v` で貼られるもの | **iPhone 側のクリップボード**。Mac のクリップボード（`write_clipboard`）は届かない |

文字を入れるときは [../apps/obsidian/README.md](../apps/obsidian/README.md) の受け渡しを使う。

## スクロールとページ送り

| 部品 | 動く方法 | 動かない方法 |
| --- | --- | --- |
| 縦に長い画面 | `scroll` を `scroll_amount: 100` で数回 | `left_click_drag`、マウスを押したまま動かす |
| ホーム画面のページ送り | `left_click_drag` で横に払う | 横方向の `scroll` |

## アプリを開く

- Spotlight では検索できないので、ホーム画面のアイコンをクリックする。ドックのフォルダやページ送りで探す

## 保存しない終わり方

編集画面で保存せずに左上の「<」で戻ると、変更は破棄される。読み取りだけのときはこの方法で戻る。入れ子の画面（設定の中の設定）は、「Cancel」→「<」→「<」と1段ずつ戻り、最後に一覧に戻ったことを確かめる。

## 画面を録画するとき（2026-10-27）

デモ映像のために、操作中のミラーリングの窓を録画する方法と決まり。

- 窓を手前に出して（画面全体の操作の許可が要る）、窓の範囲だけを `screencapture -v -C -k -R <x>,<y>,<w>,<h> -V <秒> <file>.mov` で撮る。範囲は `app_list_windows` の `bounds`（ポイント）。矢印とクリックが写る
- `-V` の時間切れで終わらせる。途中で止める（SIGINT）と保存が遅れ、同じ名前で次の録画を始めると「Failed to save」になる。撮り直しは別の名前にする
- 窓が別のデスクトップにあるときは `screencapture -x -o -l <window_id>` で1コマずつ撮れる（矢印は写らない）
- **書き出すときは、アプリの中身だけにする**（ユーザーの決まり）：窓のふちの壁紙、上の状態表示（電波・時刻・電池）を切り落とす。1コマ抜き出して境目の位置を測り、`crop` で切る。既定の大きさの窓（608×1118 ピクセルの録画）では `crop=568:988:18:110`
- アプリが出す浮かぶアイコン（SwitchBot の赤いロボット、右端）は、切る前の画像で `delogo` をかけてから切る。切ったあとにかけると、右端に赤い筋が残る（例：`delogo=x=530:y=376:w=72:h=104,crop=568:988:18:110`）
- 長い一覧を `scroll_amount: 100` で何度も送ると、iPhone のカメラが開いたことがある。録画中は 30 ほどの小さいスクロールに分ける。開いたら何もせず「OK」、`cmd+2` の App スイッチャーで元のアプリに戻る
- 元の録画は公開しないフォルダに置き、切り出した版だけを使う
